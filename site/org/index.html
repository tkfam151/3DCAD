OpenCAD for your school

Each school gets its own space: the same free app with the school's name, a place for students' cloud designs, lessons, print checks and one-click hand-ins.

Want a space for your school? Open an issue on GitHub with the school's name.

What students get

  • Print check: will it fit the school printer, will it need supports, how many grams, how long and how much.
  • Design journal laid out as the MYP design cycle (A · Inquiring, B · Developing, C · Creating, D · Evaluating), saved with the design.
  • Hand in: one ZIP for the teacher with the design, STL, screenshots, journal and print check.
  • Lessons with Pip: name keychain, phone stand, box with a lid.
  • Cloud designs that follow students between school and home, kept in the school's space.
